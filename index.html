Install

Three steps, then it speaks.

01

Download your build

The button at the top picks the right architecture automatically. If you are on a computer, use the Universal APK or scan the page on your phone.

02

Allow the install

Android asks once to allow installs from your browser or file manager. The APK is signed and needs no account; if a build signed with another key exists, uninstall it first.

03

Load the model once

Open Settings → On-device Model → Load model. It takes a few seconds and stays in memory. Then type Kurmanji text and press Generate Speech.

Not sure which one? Take the Universal build — it installs everywhere and only costs extra download size. The app itself never requests the INTERNET permission; everything above happens offline.
