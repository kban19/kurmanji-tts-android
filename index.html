Install

  1. Download the file that matches your phone (the button above chooses it for you).
  2. Open the file and allow your browser or file manager to install unknown apps when Android asks.
  3. Open Kurmanji-TTS → Settings → On-device Model → Load model once, then type Kurmanji text and press Generate Speech.

Not sure which one? Use the Universal build — it works on every device and only costs more download size. Each build is signed with the same key, so they update each other without uninstalling. Verify a download with sha256sum <file> against the hash under its name.

التحميل بالعربية

هذه نسخة كاملة تعمل دون إنترنت: 90 صوتاً، بدون أي صلاحية إنترنت، وبدون حسابات.

  1. اضغط زر التحميل في الأعلى — تختار الصفحة النسخة المناسبة لهاتفك تلقائياً.
  2. افتح الملف واسمح بتثبيت التطبيقات من هذا المصدر عند الطلب.
  3. افتح التطبيق ← الإعدادات ← تحميل النموذج مرة واحدة، ثم اكتب النص واضغط توليد الكلام.

إذا لم تعرف نوع معمارية جهازك فاختر Universal؛ سيعمل على كل الأجهزة لكن حجمه أكبر. جميع النسخ موقّعة بنفس المفتاح، لذا تُحدّث إحداها الأخرى دون حذف.
